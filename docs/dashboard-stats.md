Version 2.3.0 of Pure Blog has a redesigned dashboard and content page. The dashboard now displays a number of stats about you blogging habits, and the old "PAGES" page has been replaced with a "CONTENT" page that now allows you to manage both pages and posts from 1 place.

I've also added filtering options to the "POSTS" tab on "CONTENT" to make finding previous posts as simple as possible.

## What if I don't want stats?

That's fine, you don't have to have them. I've added an option within the `SITE SETTINGS` menu where you can change the admin homepage to the `CONTENT` page (this will also rearrange the menu items so `CONTENT` is first).

If you don't want to see the dashboard at all, there is also a checkbox to hide it from the nav menu all together (this only enables when `CONTENT` is set as the admin homepage).

![dashboard homepage](/assets/images/dashboard-stats/dashboard-homepage.png)

Even when the dashboard is hidden, you can still visit it manually by going to `/admin/dashboard.php`. {.notice .tip}
