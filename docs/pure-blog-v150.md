Since releasing Pure Blog 5 days ago, I've been pretty much coding updates to this projects during every spare second I have. This has resulted in a number of releases over the last few days, but at this point I've been able to get Pure Blog to the point where I want it to be.

I've now fully migrated [my personal site](https://kevquirk.com) to Pure Blog, and added a number of quality of life features to the project, such as:

* In [admin updates](/how-to-update-pure-blog).
* The ability to loop through [data files](/working-with-data-files).
* [Layout partials](/layout-partials) so various parts of Pure Blog can be customised over what's available in Settings, without having to fork the core project.
* Some simple stats on the Dashboard page.

So if you're a Pure Blog user, you can breathe a sigh of relief knowing that there won't be any big changes for the time being. Everything I wanted to implement is implemented at this point, so it will only be bug fixes from here on in.

There will of course be the occasional new feature and updates to Pure Blog, but my priority now is to switch to maintenance mode and just enjoy it for a while.

If you're using Pure Blog and have any feedback for me, please feel free to [get in touch](https://kevquirk.com/contact) with your feedback. I'd love to hear what you think is good or bad about Pure Blog.
